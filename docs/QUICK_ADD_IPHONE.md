# Быстрое добавление расхода с iPhone

Быстрая команда («Команды» / Shortcuts) спрашивает сумму и категорию и одним запросом отправляет расход в «Лад».
Расход попадает в приложение так же, как введённый вручную: меняет баланс, «свободно», «в день» и итоги периода.

Ниже `https://ВАШ-ДОМЕН` — адрес сайта «Лада». Точные адреса с вашим доменом показаны в
«Профиль и настройки» → «Быстрое добавление с iPhone» (кнопки «Копировать»).

## 1. Создать ключ

1. Откройте «Лад» → «Профиль и настройки» → «Быстрое добавление с iPhone».
2. Название: например `iPhone` → «Создать ключ».
3. Нажмите «Копировать» у ключа (`lad_...`). **Ключ показывается один раз**: в базе хранится только его хеш.
   Потеряли — отзовите и создайте новый.

Ключ работает только для быстрого добавления (`/api/quick/...`): посмотреть с ним профиль или другие данные нельзя.
Не больше 5 действующих ключей. Смена пароля отзывает все ключи — после неё создайте ключ заново.

## 2. Собрать команду

Приложение «Команды» → «+» → назовите команду, например «Расход». Добавьте действия по порядку.

### Шаг 1. «Запросить ввод»
- Запрос: `Сколько потратили?`
- Тип ввода: **Число**.
- Результат — переменная «Введённый текст» (дальше — «Сумма»).

### Шаг 2. «Выбрать из меню»
- Запрос: `Категория`.
- Пункты — названия ваших категорий расходов точно как в «Финансах», например: `Продукты`, `Транспорт`, `Кафе`, `Другое`.
- В каждом пункте добавьте действие «Текст» с тем же названием. После меню результат — «Результат меню» (дальше — «Категория»).

Если категорию не нашли (опечатка, переименовали), расход всё равно запишется — в «Без категории».

> Вариант со списком категорий с сервера (меню обновляется само):
> «Получить содержимое URL» `https://ВАШ-ДОМЕН/api/quick/categories` (метод GET, заголовок `Authorization`, как ниже)
> → «Получить значение словаря» по ключу `names` → «Выбрать из списка».

### Шаг 3. «Получить содержимое URL»
- URL: `https://ВАШ-ДОМЕН/api/quick/expense`
- Метод: **POST**.
- Заголовки:
  - `Authorization` — `Bearer lad_ВАШ_КЛЮЧ` (слово `Bearer`, пробел, ключ);
  - `Content-Type` — `application/json`;
  - необязательно `Idempotency-Key` — переменная «Текущая дата» в формате ISO или любой уникальный текст. Если связь
    плохая и команда отправит запрос повторно, второй расход не создастся (повтор узнаётся 10 минут).
- Текст запроса: **JSON**, поля:
  - `amount` — Число → переменная «Сумма»;
  - `category` — Текст → переменная «Категория»;
  - по желанию `comment` (Текст), `date` (`2026-10-29`; без поля — сегодня по часовому поясу профиля),
    `ledger` — `personal` (личные, по умолчанию) или `household` (семейные).

### Шаг 4. «Показать уведомление»
- Добавьте «Получить значение словаря» по ключу `message` из «Содержимого URL», затем «Показать уведомление» с этим
  значением. Пример текста: «Записано 350 ₽, «Продукты». Баланс 12 000 ₽, свободно 8 000 ₽ до 5 ноя, в день 1 142,86 ₽.»
- Если сервер ответил ошибкой, в ответе вместо `message` будет `detail` с текстом ошибки (см. таблицу ниже).

Готово. Команду можно вынести на экран «Домой» или запускать голосом: «Привет, Siri, Расход».

## Пример запроса (curl)

```bash
curl -X POST "https://ВАШ-ДОМЕН/api/quick/expense" \
  -H "Authorization: Bearer lad_ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 2026-10-29T14:05:11+03:00" \
  -d '{"amount": 350, "category": "Продукты", "comment": "Пятёрочка"}'
```

Локальная проверка (`lad-local`): адрес `http://localhost:8100/quick/expense` (без `/api`).
В PowerShell вместо `curl` используйте `curl.exe`, а кавычки внутри JSON экранируйте: `-d '{\"amount\": 350}'`.

## Пример ответа (200)

```json
{
  "ok": true,
  "duplicate": false,
  "transaction_id": 57,
  "ledger": "personal",
  "amount": "350.00",
  "currency": "RUB",
  "category": "Продукты",
  "category_found": true,
  "occurred_on": "2026-10-29",
  "balance": "12000.00",
  "free": "8000.00",
  "free_until": "2026-11-05",
  "daily_allowance": "1142.86",
  "message": "Записано 350 ₽, «Продукты». Баланс 12 000 ₽, свободно 8 000 ₽ до 5 ноя, в день 1 142,86 ₽."
}
```

- `duplicate: true` — это повтор с тем же `Idempotency-Key`: новый расход не создан, показан прежний.
- `free`, `free_until`, `daily_allowance` равны `null`, если не задан следующий основной доход; тогда пояснение есть в `message`.
- Сумму можно прислать и строкой с запятой: `"350,50"`.

## Ошибки

| Код | Когда | Что делать |
| --- | --- | --- |
| 401 | Ключ неверный, отозван, сменили пароль, удалён аккаунт | Создать новый ключ в профиле и вставить в команду |
| 404 | Финансы этой книги (личной или семейной) не включены | Включить в разделе «Финансы» |
| 422 | Сумма 0 или меньше («Сумма должна быть больше нуля»), суммы нет | Проверить шаг 1 команды |
| 429 | Больше 30 запросов в минуту по ключу (или 60 с одного адреса) | Подождать минуту |

Категории для меню: `GET https://ВАШ-ДОМЕН/api/quick/categories` (`?ledger=household` — семейные) →
`{"ledger": "personal", "names": ["Продукты", ...], "categories": [{"id": 1, "name": "Продукты"}, ...]}`.
